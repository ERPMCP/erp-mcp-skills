# ERP MCP 连接检查规则

## 目标

Skill 不应该等用户在聊天里补一句“请连接 ERP MCP”。每次需要读取 ERP 数据时，都必须先检查当前会话是否已经有可用的 `erp` MCP 工具。

## 查询前必须检查

1. 当前会话是否能看到 `erp` MCP。
2. 是否能看到 ERP 查询工具，例如统计、合同财务、房源、小区行情等工具。
3. 如果工具正在连接，先等待一次再判断。
4. 如果需要授权，提示客户重新授权或更新 Token。
5. 如果连接器被禁用，提示客户启用。
6. 如果当前任务没有加载 ERP 连接器，提示客户到 WorkBuddy/Codex 的连接器或插件设置里启用。

## 不允许的行为

- 不允许先生成正式看板，再在看板里显示“等待查询”。
- 不允许把没有连接 MCP 的结果写成 0。
- 不允许编造“已经连接”。
- 不允许让客户输入接口名、工具名或字段名。
- 不允许把技术报错直接丢给客户。

## 客户能听懂的提示

### 当前任务没有 ERP 连接器

当前任务还没有加载 ERP 连接器，所以我不能直接读取 ERP 数据。请先在连接器或插件设置里启用 `erp`，然后重新查询。

### ERP 需要重新授权

ERP 连接需要重新授权。请在连接器里重新登录或更新访问令牌。

### ERP 连接器被关闭

ERP 连接器目前是关闭的。请先启用 ERP 连接器，再重新查询。

### 插件已带配置但缺 Token

插件已经带了 ERP 连接配置，但还缺访问令牌。请填写 ERP MCP Token。真实 Token 不要发到公开仓库。

## 技术说明放哪里

接口名、工具名、原始错误、请求参数只放在折叠区：`数据来源与技术说明`。
