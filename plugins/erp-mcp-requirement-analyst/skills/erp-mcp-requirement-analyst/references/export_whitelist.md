# 系统支持导出的表格白名单

Skill 只能建议客户导出以下表格：

1. 付款明细导出；
2. 合同信息导出；
3. 实收明细导出；
4. 业绩明细导出：
   - 应收应付；
   - 业绩分配；
5. 人员信息导出：
   - 汇总；
   - 人员列表。

## 绝对禁止

系统当前**不支持单独导出房源表**。因此，任何场景都不得建议客户导出：

- 房源表；
- 房源明细表；
- 在售房源表；
- 新上房源表；
- 带“新上时间”或“录入时间”的房源表；
- 房源历史表；
- 其他名称不同、实质仍是房源导出的表格。

## 房源字段不够时怎么处理

只能按以下顺序处理：

1. 使用 ERP MCP 已经能查到的房源字段；
2. 将“历史月份官方数量”和“当前房源列表”分开说明，不能混成同一口径；
3. 给客户一个能完成到什么程度的方案；
4. 说明哪些结果只能作为参考；
5. 建议向产品顾问反馈新增房源历史日期、组织归属或明细接口；
6. 不得虚构系统存在房源导出功能。

`scripts/recommend_export.py` 必须读取白名单。任何推荐表名不在白名单中时，脚本必须拒绝输出并记录校验错误。
